\
สวัสดีค่ะ\
คาวาซากิ ซากุระ ค่ะ\
\
ซิงเกิ้ลที่ 43 นี้ ก็ได้รับมอบหมายให้ดำเนินกิจกรรมในฐานะเซมบัทสึเมมเบอร์อีกครั้งค่ะ\
\
ทั้งหมดนั่นก็เป็นเพราะทุก ๆ ท่านที่คอยให้การสนับสนุนมาโดยตลอดค่ะ\
ต้องขอขอบคุณจริง ๆ เลยนะคะ\
\
\
ในซิงเกิ้ลนี้ได้รับเลือกให้ยืนตำแหน่งที่เรียกว่า front ค่ะ\
เป็นอีกครั้งที่ได้กลับมายังที่แห่งนี้ ดีใจมาก ๆ เลยล่ะค่ะ\
\
\
\
และที่ข้าง ๆ นั้น คนที่ได้รับตำแหน่ง center ก็คือ อิโนะอุเอะ นางิ ค่ะ\
\
\
ช่วงนี้พอได้เห็นนางิแล้วก็รู้สึกว่า นางิดูผ่อนคลายมากขึ้น คุยกับผู้คนหลากหลายมากขึ้น แล้วก็ดูสนุกกับการเป็นไอดอลมากขึ้น\
\
พอได้เห็นแบบนั้นแล้ว ในฐานะที่เป็นเพื่อนร่วมรุ่นแล้วก็ รู้สึกดีใจมาก ๆ เลยล่ะค่ะ\
\
\
\
ที่ผ่านมา เวลาที่นางิแบกรับภาระหนักอึ้งในช่วงเวลาสำคัญของวงเอาไว้นั้น พอเห็นแบบนั้นแล้ว ก็รู้สึกอยากจะคอยช่วยเป็นพลังให้กับเธอได้บ้าง แต่กลับไม่สามารถยื่นมือเข้าไปช่วยเหลืออะไรได้เลย รู้สึกเจ็บใจมาโดยตลอดเลยล่ะค่ะ\
\
\
เพราะอย่างงั้น ซิงเกิ้ลนี้ก็เลยอยากให้นางิได้รู้สึกสนุกอย่างเต็มที่ค่ะ\
\
\
ฉันเองก็อยากที่จะเติบโตให้มากขึ้นกว่านี้ อยากเป็นคนที่ทำให้หัวใจของนางิรู้สึกผ่อนคลายมากขึ้น เมื่อได้เหลือบมองมาข้าง ๆ ค่ะ\
\
\
แล้วก็ได้รับเลือกให้ยืนตำแหน่งคู่กับมิทสึกิจังเป็นครั้งแรกด้วย ตั้งหน้าตั้งตารอเลยล่ะค่ะ !\
\
อยากจะให้เป็นช่วงเวลาที่มิทสึกิได้แสดงให้เห็นถึงความเป็นมิทสึกิออกมาจังเลยนะ\
\
\
_[รูป 1]_\
\
\
\
\
\
อีกอย่าง ฉันเองก็ มีความฝันที่อยากจะให้มันเป็นจริงค่ะ\
\
\
ที่จริง เร็ว ๆ นี้ ความฝันที่เคยคิดว่ามันคงไม่มีทางเป็นจริงอีกต่อไปแล้ว ก็ได้เป็นจริงขึ้นมาค่ะ\
\
ถึงต่อหน้าจะเคยบอกว่ายังไม่อยากยอมแพ้ แต่ลึก ๆ ในใจแล้ว พอมาคิดตามความเป็นจริง ก็เคยคิดว่ามันคงไม่มีทางเป็นจริงแล้วล่ะค่ะ\
\
เพราะงั้น การที่มีเรื่องราวสุดเหลือเชื่อเกิดขึ้นมาจริง ๆ บนโลกใบนี้เนี่ย มันเป็นความรู้สึกที่ช่างน่าประหลาดใจอย่างบอกไม่ถูกเลยล่ะค่ะ\
\
\
ในตอนนี้ที่ความฝันที่เกือบจะล้มเลิกไปแล้วได้เป็นจริงขึ้นมา\
ก็รู้สึกว่าดีจริง ๆ ที่ตอนนั้นไม่ได้ยอมแพ้ไปซะก่อนค่ะ\
\
ตอนนี้เองก็กำลังจดจ่อกับการทำบางสิ่งบางอย่างทิ้งไว้ในงานชิ้นนั้นอยู่\
และสักวันหนึ่ง มันก็จะส่งต่อไปยังเหล่ารุ่นน้อง เชื่อว่านี่คือสิ่งที่ฉันจะต้องทำค่ะ\
\
\
การไล่ตามความฝันนั้น ก็มีช่วงเวลาที่ต้องรู้สึกเจ็บปวดอยู่เหมือนกันนะคะ\
แต่ถึงอย่างงั้น ถ้าหากวันหนึ่งจะต้องมานั่งเสียใจภายหลังแล้ว\
ฉันก็อยากที่จะ มุ่งหน้าไขว่คว้าความฝันด้วยกำลังของตัวเองค่ะ\
\
\
ในซิงเกิ้ลที่ 43 นี้ก็ จะไม่ลืมความรู้สึกที่แสนสำคัญต่อโนกิซากะ และก็จะพยายามไปกับเมมเบอร์ทุก ๆ คนอย่างเต็มที่ เพื่อที่จะได้ส่งต่อความรู้สึกขอบคุณนี้ให้ได้มากที่สุดเท่าที่จะทำได้ค่ะ !\
\
จะรู้สึกดีใจมาก ๆ เลยล่ะค่ะ ถ้ากรุณาอยู่ด้วยกันไปจนถึงท้ายที่สุด\
\
\
ต่อจากนี้ก็ ขอฝากเนื้อฝากตัวด้วยนะคะ !\
\
\
\
\
ไว้จะมาเขียนใหม่นะ\
\
\
\
